# Alteora Academy Website

A responsive school website built with HTML and CSS.

## Files

* `index.html` — page structure and content
* `style.css` — complete responsive design
* `script.js` — mobile navigation, modal video placeholder, form feedback, animations and dynamic year

## Run

1. Extract/open the folder in VS Code.
2. Open `index.html` in a browser.
3. For the best development experience, use the Live Server extension in VS Code.

## Notes

The images are loaded from Unsplash, so an internet connection is required for them to appear.

The enquiry form is a front-end demo. To receive real submissions, connect it to a backend, Formspree, EmailJS, or another form service.

The video modal is a placeholder ready for a real school video/YouTube embed.
